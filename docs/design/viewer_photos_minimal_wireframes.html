Result viewer — less chrome, more figure

The shipped Tufte pass removed Inspect / X,Y / Max-Min, but the screen is still a stack of white panels: finding caption, five-button row, scale card, stats card, scrubber card. Google Photos keeps the photo full-bleed and lets chrome appear only when you need it.

Constraint kept: five fields one-tap, tap-to-probe, Share / ⓘ / Home / Back, summary GIF before frame 1, sequence colour scale when N>1, sweep START_FRAME skip. What changes is where those live on screen.
