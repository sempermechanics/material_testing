Operator

Read-only. Minting, renewing and revoking a licence, and approving or suspending an account, all require a device-attested staff session — an ECDSA signature from a registered device key, which a browser has no way to produce. That is deliberate: it means a stolen session cookie or ID token cannot issue licences. Those operations stay on the phone admin screen and the staff CLI; this page is for looking things up.
